Projelerim

Yazılım geliştirme serüvenimde farklı teknolojileri harmanlayarak projeler üretiyorum. Statik web tasarımlarından dinamik veritabanı yönetim sistemlerine, PHP ve SQL tabanlı backend yapılarından Node.js ve React.js ile geliştirilen modern arayüzlere, Docker ile konteynerleştirilen uygulamalara kadar geniş bir yelpazede kod yazıyorum.


  • Frontend Geliştirme (HTML, CSS, JS)
    Kullanıcı dostu, responsive ve modern arayüz tasarımları.
  • Backend Geliştirme (PHP)
    Veri akışını yöneten, güvenli arka plan sistemleri.
  • Veritabanı Yönetimi (SQL)
    Kullanıcı verilerinin ve içeriklerin güvenli şekilde saklanması.
  • Node.js
    JavaScript ile sunucu taraflı, hızlı ve ölçeklenebilir uygulamalar geliştirme.
  • React.js
    Bileşen tabanlı, dinamik ve etkileşimli kullanıcı arayüzleri oluşturma.
  • Docker
    Uygulamaları konteynerlere alarak her ortamda tutarlı çalışmasını sağlama.

HTML Nedir?

Web sayfasının iskeletidir. Yapıyı belirler.

CSS Nedir?

Web sitesinin makyajıdır. Renk ve düzeni sağlar.

JavaScript Nedir?

Sitenin kaslarıdır. Hareket ve etkileşim sağlar.

Node.js Nedir?

JavaScript'i sunucu tarafında çalıştırmamızı sağlayan çalışma ortamıdır.

React.js Nedir?

Kullanıcı arayüzleri oluşturmak için kullanılan JavaScript kütüphanesidir.

Docker Nedir?

Uygulamaları taşınabilir konteynerler haline getiren bir platformdur.
